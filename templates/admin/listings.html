Every imported row is published immediately, same as the Add Listing form — the pending queue is only for what the public sends in. A row with no title is skipped and counted; a compound_slug that matches nothing is imported unlinked and reported, not dropped.

Columns (only title is required):
title, listing_type, compound_slug, area, location, unit_type, bedrooms, bathrooms, area_sqm, price, rent_amount, rent_cadence, price_per_week, high_season_multiplier, currency, furnishing, condition, legal_status, seller_type, negotiable, owner_name, owner_phone, owner_email, image_url

listing_type defaults to resale. furnishing must be one of unfurnished / semi / furnished; condition one of New / Excellent / Good / Needs Renovation; legal_status one of registered_title / court_validated / preliminary_contract / unknown; seller_type one of owner / agent. Blank is allowed for all four. A row with an unrecognised value is rejected and named, never silently blanked.
